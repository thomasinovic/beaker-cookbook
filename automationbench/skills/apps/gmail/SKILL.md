This is the operating procedure for the Gmail app (send, find, label, threads, drafts, etc.).

When a request points to an unspecified inbox message or several messages could update the same record, gather the plausible messages before changing a record or sending a confirmation. Compare the sender, exact subject and entity, message date, and any correction or retraction; use the latest applicable instruction. If a narrow search returns only one plausible message but does not establish that it is the requested one, widen the search with related terms and check the other matches.
